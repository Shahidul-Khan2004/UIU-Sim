UIU SIMPLE BENCH - UNITY 3D ASSET

This is the simplified bench approved in the preview:
- 7 long grey seat slats
- 5 long grey back slats
- simple orange/brown side frame
- simple orange/brown armrests
- no complicated curves or decorative geometry

THIS PACKAGE CONTAINS AN ACTUAL 3D MODEL.
The Unity C# helper does NOT generate the mesh.

PRIMARY MODEL
  Models/SimpleBench.obj

OPTIONAL
  Models/SimpleBench.glb

APPROXIMATE REAL-WORLD SIZE
  Width: 1.50 m
  Depth: 0.52 m
  Seat height: 0.45 m
  Overall height: 0.82 m

UNITY INSTALL
1. Extract this ZIP into the ROOT of the Unity project.
2. Wait for Unity to finish importing.
3. The model is already usable at:
   Assets/Art/Furniture/SimpleBench_3D/Models/SimpleBench.obj

RECOMMENDED PREFAB SETUP
Run:
  Tools > UIU Simulator > Assets > Create Simple Bench 3D Prefab

Unity creates:
  Assets/Art/Furniture/SimpleBench_3D/Prefabs/PF_SimpleBench_3D.prefab

The helper:
- creates URP-compatible materials
- assigns the grey/orange colors
- enables GPU instancing
- adds simple colliders
- saves the imported OBJ as a reusable prefab
