UIU ROUND CAFE TABLE - UNITY 3D ASSET

This package contains an ACTUAL pre-generated 3D mesh.
It is a simplified version of the round cafe table from the reference:
- round wood top
- four black metal legs
- no lower shelf / no extra bottom details

PRIMARY MODEL
  Models/RoundCafeTable.obj

ALSO INCLUDED
  Models/RoundCafeTable.glb
  Models/RoundCafeTable.mtl
  Textures/RoundTable_Wood_BaseColor.png
  Editor/CreateRoundCafeTablePrefab.cs

SIZE
  Diameter: ~0.74 m
  Height: ~1.02 m

UNITY SETUP
1. Extract this ZIP into the ROOT of the Unity project.
   It will create:
   Assets/Art/Furniture/RoundCafeTable_3D/

2. Wait for Unity to finish importing.

3. The OBJ itself is immediately usable:
   Assets/Art/Furniture/RoundCafeTable_3D/Models/RoundCafeTable.obj

4. Recommended: run
   Tools > UIU Simulator > Assets > Create Round Cafe Table 3D Prefab

5. The reusable prefab will be created at:
   Assets/Art/Furniture/RoundCafeTable_3D/Prefabs/PF_RoundCafeTable_3D.prefab

The helper script only:
- creates URP-compatible wood/black-metal materials
- assigns the included wood texture
- enables GPU instancing
- adds simple colliders
- saves the OBJ as a reusable prefab

The geometry is already contained in the OBJ.
