UIU WOOD SLOTTED CAFE CHAIR - UNITY 3D ASSET

This package contains an ACTUAL pre-generated 3D mesh.
The Unity Editor script does not generate the chair geometry.

PRIMARY MODEL
  Models/WoodSlottedCafeChair.obj

ALSO INCLUDED
  Models/WoodSlottedCafeChair.glb
  Models/WoodSlottedCafeChair.mtl
  Textures/Wood_BaseColor.png
  Editor/CreateWoodSlottedCafeChairPrefab.cs

SIZE
  Width: ~0.49 m
  Depth: ~0.48 m
  Seat height: ~0.46 m
  Overall height: ~0.99 m

UNITY SETUP
1. Extract this ZIP into the ROOT of the Unity project.
   It will create:
   Assets/Art/Furniture/WoodSlottedCafeChair_3D/

2. Wait for Unity to finish importing.

3. The OBJ itself is immediately usable:
   Assets/Art/Furniture/WoodSlottedCafeChair_3D/Models/WoodSlottedCafeChair.obj

4. Recommended: run
   Tools > UIU Simulator > Assets > Create Wood Slotted Cafe Chair 3D Prefab

5. The reusable prefab will be created at:
   Assets/Art/Furniture/WoodSlottedCafeChair_3D/Prefabs/PF_WoodSlottedCafeChair_3D.prefab

The prefab helper only:
- creates URP-compatible wood/chrome materials
- assigns the included wood texture
- enables GPU instancing
- adds simple colliders
- saves the OBJ as a reusable prefab

The geometry is already contained in the OBJ.
